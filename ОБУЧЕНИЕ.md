# Проект №5 — Shop.co

Это интернет-магазин одежды по макету Shop.co. Все изображения находятся локально в `public/images`: `hero` — главный баннер, `products` — товары, `styles` — категории стиля, `brands` — логотипы.

`src/app` содержит страницы сайта. `src/components` содержит повторно используемые блоки: шапку, карточки товаров, корзину, отзывы и футер. `src/data` хранит данные товаров. `package.json` хранит зависимости и команды запуска.

## Запуск

1. Откройте терминал в этой папке.
2. Выполните `npm install`.
3. Выполните `npm run dev`.
4. Откройте `http://localhost:3004/`.
